# Rubio 2028 Campaign Site

Hypothetical presidential campaign website for an AP Government & Politics project.

**Live site:** [https://brogan-riley21.github.io/rubio-campaign/](https://brogan-riley21.github.io/rubio-campaign/)

## Files required on GitHub (root of repo)

- `index.html` — main page (required for the site to load)
- `styles.css`
- `script.js`
- `images/` — folder with all photos and logos

If `index.html` is missing, GitHub Pages shows this README instead of the website.
